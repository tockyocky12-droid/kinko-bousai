# きんこう防災ナビ（試作）

錦江町の土砂災害警戒区域などを、スマホで1つの地図で見られるWebアプリ（PWA）の試作です。
地図・オフライン対応などの仕組みは「錦江町森林ナビ」（tockyocky12-droid/my-first-repo）を土台にしています。

公開URL：https://tockyocky12-droid.github.io/kinko-bousai/

**町の公式の防災情報ではありません。避難情報は町の発表・防災行政無線で確認してください。**

## いま載っているもの（v1）

| 情報 | 入手先 | 持ち方 |
|---|---|---|
| 背景の地図（淡色・標準・写真） | 地理院タイル（国土地理院） | 表示のたびに配信元から読む |
| 土砂災害警戒区域・特別警戒区域（土石流・急傾斜地・地すべり） | 重ねるハザードマップ（国土交通省・国土地理院） | 同上（自前でデータを持たない）。最初から表示 |
| 洪水・津波・高潮の浸水想定 | 同上 | 同上。「重ねる」で選んだときだけ表示 |
| 気象警報・キキクル・県の河川砂防情報システムなど | 気象庁・鹿児島県・錦江町 | 外部サイトへのリンク |

## これから載せる予定

避難所・避難場所、警察・消防・病院、AED、消火栓・防火水槽（公開してよいか防災担当・消防と確認してから）。

## 守ること

- 個人名の入ったデータ（避難行動要支援者名簿など）は、このリポジトリに置かない。
- 消火栓・防火水槽などの位置を公開してよいかは、防災担当・消防と確認してから載せる。
- 各データの出典と更新日を、アプリ内（「i」の画面）に必ず書く。

## 仕組みのメモ

- 地図ライブラリ Leaflet 1.9.4 は `lib/leaflet-1.9.4/` に自前で置く（外部CDNに頼らない）。
- `sw.js` でオフライン対応。**更新のたびに `sw.js` の `VER` と `index.html` の `APP_VER` を同じ番号で上げる。**
- 地図画像は `crossOrigin='anonymous'` で読み、中身の見えない形（opaque）では保存しない。保存枚数は背景・ハザードとも3000枚まで。
- 重ねるハザードマップは、区域の無い所で「無し（404）」を返す。この返事も保存して、同じ所を何度も問い合わせない。
- 通信量を抑えるため、拡大率10未満（町全体より広い表示）ではハザードの画像を読まない。Webフォントも使わない。
- 端末の記録（表示位置など）は、同じサイトの森林ナビと混ざらないよう `bousai:` を頭に付けて保存する。

```
cd ..                      # このリポジトリの1つ上のフォルダ

```
